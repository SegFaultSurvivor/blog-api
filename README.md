## Highlights:

- 🌟 **Tech Stack**: Node.js, Express, In-memory storage
- 💡 **CRUD Operations**: Create, Read, Update, Delete blog posts
- 🗄️ **In-Memory Storage** for posts
- 🖊️ **Flexible API** for adding and modifying posts

---

### Start api.js file (Port: 4000)
```shell
nodemon api.js
```
### Start index.js file (Port: 3000)
```shell
nodemon index.js
```
